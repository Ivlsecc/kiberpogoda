# Задача 1 — пассивный сбор и ранжирование целей

Собирает по компаниям отрасли открытые сигналы и ранжирует их как потенциальные
цели под разные профили злоумышленника. Методология — модель A-E-O-I (ценность,
поверхность, возможность, намерение), подробный разбор в отчёте.

Весь сбор пассивный: читаются только опубликованные данные — CT-логи, Wikipedia
Pageviews, публичные вакансии hh.ru. Хосты компаний не резолвятся и не опрашиваются.

## Запуск

```bash
pip install -r requirements.txt

python src/main.py                       # live-сбор + скоринг по всем профилям
python src/main.py --offline             # без сети, на приложенных данных
python src/main.py --profile hacktivist  # отдельный профиль
```

Отдельные модули:

```bash
python src/surface.py                                  # разбор поверхности из CT
python src/validate.py --offline --profile ransomware  # бэктест: Precision@k, AP, lift
python src/sensitivity.py --offline --profile ransomware --n 1000  # устойчивость к весам
python tests/test_scoring.py                           # тесты
```

## Результаты (output/)

- `signals.json` — собранные сигналы по компаниям (флаг `collected`: live/фолбэк)
- `ranking_<profile>.csv` — ранжирование (разделитель `;`, UTF-8-BOM под Excel)
- `ranking.md` — сводка по всем профилям с ключевыми драйверами
- `validation_*.json`, `sensitivity_*.json` — бэктест и устойчивость вывода

## Что показали реальные данные

`surface.py` на `data/ct_real.json` (поддомены 10 компаний из публичных CT-логов):

| домен | хостов в CT | высокоценных |
|---|---:|---:|
| lenta.com | 163 | 20 |
| magnit.ru | 108 | 7 |
| mvideo.ru | 103 | 6 |
| ozon.ru | 60 | 0 |
| wildberries.ru | 31 | 3 |

Самые известные бренды (Wildberries, Ozon) светят в CT меньше всего — прячут
инфраструктуру за wildcard-сертификатами. Середняки (Лента, М.Видео, Магнит)
выставляют наружу десятки dev/test и высокоценных хостов: секрет-менеджеры, VCS,
SSO, портал поставщиков. Публичность бренда и реальная поверхность атаки связаны
слабо (Спирмен 0.43 по числу хостов, 0.14 по ценным узлам) — это переворачивает
наивный ответ «кто крупнее, того и бьют».

## Ограничения

- Wikipedia Pageviews доступен глобально — собирается вживую в любом окружении.
- `hh.ru` и `crt.sh` отвечают с РФ-сети; из зарубежных IP возможны 403/502 — тогда
  берётся приложенный seed (поле `collected=false` в `signals.json`).
- Признаки группы A — оценки по публичной отчётности и масштабу бренда, а не единый
  автоисточник (в проде берутся из реестров ЕГРЮЛ/Rusprofile/Checko).
- CT показывает выпущенные сертификаты, а не живые хосты; wildcard искажает картину.
- Веса профилей — экспертная гипотеза, калибруются по ретро-данным об инцидентах.
- Всё — внешний взгляд: оценивается интерес и привлекательность, а не состояние защиты.
